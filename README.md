## 🧠 Overview

Auto-Rig Pro is a character rigging and animation add-on for Blender designed to help artists build production-ready skeletons and prepare 3D characters for animation. It provides tools for creating armatures, configuring bone structures, and managing character deformation within a unified workflow.

The add-on supports a range of character types, including humanoid characters and other articulated models. Its rigging tools help streamline common tasks such as setting up bones, adjusting rig controls, and preparing meshes for movement.

Auto-Rig Pro also includes features for transferring animation data between compatible rigs and importing motion-capture animation. These capabilities can help artists integrate character animation into modeling, game development, and 3D production pipelines.

By bringing rigging and animation utilities into Blender, Auto-Rig Pro can reduce repetitive setup work and provide a more organized process for animating characters.
